# Smooth manifolds

Use coordinate charts, tangent spaces, and smooth maps.

Smooth manifolds use compatible local coordinate charts, not necessarily one global coordinate system.

Scope: Focused first lesson with explicit assumptions and worked examples; not an exhaustive treatment or a substitute for subsequent proofs and independent practice.
