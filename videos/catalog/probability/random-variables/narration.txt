A random variable assigns a number to each outcome of a random experiment. For two independent fair coin tosses, let X count heads. Different outcomes can receive the same numerical value: head-tail and tail-head both map to one.

Each ordered coin outcome has probability one quarter, but the values of X are not equally likely. Zero heads has one supporting outcome, one head has two, and two heads has one. Grouping outcomes creates the variable's probability distribution.

A new numerical rule creates another random variable. If Y equals twice X minus one, its possible values are negative one, one, and three. The mapping changes the numerical labels while preserving the probabilities attached to these three distinct groups.

An event about a random variable corresponds to a collection of original outcomes. At least one head includes head-head, head-tail, and tail-head, so its probability is three quarters. Keep the outcome, its numerical value, and its probability conceptually separate.
