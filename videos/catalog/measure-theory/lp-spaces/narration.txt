An L two norm measures a function's size by integrating its squared magnitude and taking a square root. It treats the entire function as one vector. For the function x on the unit interval, the norm is one over square root three.

A function equal to one on an interval of width one quarter and zero elsewhere has squared integral one quarter. Its L two norm is therefore one half. Both height and the measure of the supporting region determine the norm.

Shrinking support alone need not shrink the norm. Set the height to square root n on the open interval zero to one over n, and zero elsewhere. Squared area remains one, yet every fixed input eventually has value zero.

Functions that differ only on a measure-zero set have zero L two distance. The space therefore identifies them as the same vector. A spike at just one point changes a drawn value but not the corresponding equivalence class or norm.
