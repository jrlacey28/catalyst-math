# Lebesgue integration

Integrate measurable functions and apply monotone and dominated convergence.

Lebesgue integration weights values by measurable size; exchanging limits requires hypotheses.

Scope: Focused first lesson with explicit assumptions and worked examples; not an exhaustive treatment or a substitute for subsequent proofs and independent practice.
