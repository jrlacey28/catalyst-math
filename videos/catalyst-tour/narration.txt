Start with one idea
Welcome to Catalyst. This walkthrough takes you from getting the software to a useful learning session. We will follow one idea: how changing a function changes its graph, and why algebraic steps work. Everything shown uses a separate demo learner.

Get the open-source software
Start with the Catalyst offline ZIP supplied with this project. It includes the app and all the rendered lesson videos. The smaller source ZIP contains the code, transcripts and exercises. Extract the archive into a normal folder before opening anything. Catalyst's original code and shared lessons use the included MIT license. The upstream repository is currently private, so use the provided archive rather than expecting a public GitHub download.

Launch on your computer
Install Python three point ten or newer from python dot org. On Windows, open the extracted Catalyst folder and double click Start Catalyst. If Python is not found, finish Python setup and check that the python command works. On Mac or Linux, open a terminal in that folder and run python three, space, start dot py. Keep the terminal open. In your browser, open the local address shown here. Stop the server with Control C when finished.

Make your own learning space
Choose the learner name to create your own learning space. Pick a starting path and how you like to work. These preferences choose your first activity; they do not give you a test score. Each learner has separate saved work on this computer. You can return without starting over.

Find your starting point
If you are unsure where to begin, choose Find my level. The assessment asks one question at a time and adapts across several areas. Say when you do not know. Its recommendation is a starting estimate, not a permanent label. You can also browse Courses directly, from number sense through college topics.

Watch, then understand
Open a topic and watch its short narrated animation. Pause, replay, or use captions and chapters. Then open the study guide when one is available. Read the worked example and ask what changed at each line, and why. Here, a function is a rule: changing the input changes the output. Prerequisite links help repair a missing step before you continue.

Explore the math playground
The playground now brings the interactive tools together. Free exploration lets you change a graph or diagram. Guided reasoning explains valid transformations. Applied models connect several ideas to a situation. In the function lab, predict what changing the coefficient will do. Adjust it, watch the graph move, and compare the result with your prediction. Change one thing at a time.

Understand why a step works
When a simplification feels like a jump, open Why this step. Reveal one transformation and its reason at a time. In the expression comparison, the quotient simplifies to a line everywhere except the excluded input. The missing point still matters. Matching graph shapes is a useful observation; factoring and the domain restriction explain why the expressions agree where both are defined.

Try three problems
Return to Practice and try the three questions. Start with Build the idea, then Connect the steps and Stretch and transfer. Write your method as well as your answer. If you are stuck, ask for a hint. Check the feedback, find the first uncertain step, and try another variation. Getting help is part of learning.

Check independently
When you can explain the method, take a fresh independent check. Hinted or previously exposed questions do not establish new independent readiness. A passed check is useful evidence, but one short session does not prove lasting mastery. Some written work needs a tutor's review. Watching a video alone never passes a lesson.

Put ideas together
Apply the math connects ideas in a real model. Choose an investigation, make a prediction, change a control, and explain what you observe. The motion model links position, time and rate of change. Worked examples prepare you for three practice questions and a larger written project. State your assumptions and units as you reason.

Keep and improve your reasoning
My homework brings your saved writing together. Review my reasoning helps you inspect assumptions, transformations, notation and conclusions. Save a revised explanation and say what changed. Earlier versions stay available. You can copy your work for a tutor, or open the optional tailoring workspace with your actual saved explanation.

Review and make it personal
Mixed review gives fresh three-question sets across supported skills and suggests later retrieval. An empty due list is normal before you have qualifying work to review. Tailor to my interests connects a topic with your goals. Its copyable tutor brief works without AI. An optional local Ollama model can offer unverified help; it does not grade you.

A learning rhythm you control
Keep this rhythm: understand, predict, explore, try, explain, and return later. Move quickly when the evidence supports it, and revisit foundations whenever a step feels unclear. Your progress stays on disk. Use the written getting-started guide for setup and backup instructions. Begin with one idea, and make it yours.
