# Catalyst

**See it. Try it. Make math click.**

A free, open-source math learning app that runs on your computer. Explore 159 introductory narrated lessons across 29 courses, from counting through advanced college topics. Watch an idea, try three problems, understand the steps, and use it in a live model.

[Download the latest release](https://github.com/jrlacey28/catalyst-math/releases/latest) · [Watch the one-minute intro](https://github.com/jrlacey28/catalyst-math/releases/download/v0.10.2/catalyst-intro.mp4)

## Start in a few minutes

1. Get **catalyst-offline.zip** and extract it completely. It includes all lesson videos. The smaller **catalyst-source.zip** contains the app, exercises, transcripts and editable source, without rendered videos.
2. Install [Python 3.10 or newer](https://www.python.org/downloads/).
3. In the extracted **catalyst** folder, open **Start Catalyst.cmd** on Windows. On macOS/Linux, run `python3 start.py` in Terminal.
4. Keep that terminal open and visit **http://127.0.0.1:8766** in your browser.

No paid account, API key, or extra Python package is required to use the app. Optional local AI and video-authoring tools have separate setup.

## A useful learning session

- **Choose a starting point.** Take the placement check or choose a course. Each person gets a separate local learning space.
- **Watch and try.** The video and three practice problems live on the same page. Open an example, a hint, the calculator, or the corner coach when stuck.
- **Understand the step.** See why an algebraic move is allowed, then try a fresh variation yourself.
- **Make it real.** Explore physics, mechanical and electrical engineering, architecture, finance, and AI with controls that change a model.
- **Check and revisit.** Independent checks earn stars on the skill tree. Review earlier ideas to keep them useful.

These are focused introductions, practice, and explorations—not complete university degree courses. Written explanations and advanced proofs need tutor review. Watching a video or moving a control does not automatically demonstrate mastery. Optional AI replies are unverified help, never grades.

## Your work stays with you

Drafts save as you work, with a one-minute safety check. Wait for **Saved** after making changes. Return by launching from the same folder. Autosave never submits a test.

For a backup, stop the app and copy the whole extracted folder. Smaller backups must preserve **students/** and **student/**. The readable JSON export has no import feature. Progress does not automatically sync between computers.

Share the clean release ZIP, not your personal learning folder. Profiles are local convenience, not password-protected accounts; the localhost server is not ready for public multi-user hosting.
