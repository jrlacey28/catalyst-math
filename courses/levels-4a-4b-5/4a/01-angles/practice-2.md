# 4A-01 — Practice set 2

Try these three problems. Show enough working to explain your method. Ask questions if you get stuck; help is welcome during practice.

1. **4A-01-P4** Parallel lines are cut by a transversal. One corresponding angle is 112°. Find the matching angle.

2. **4A-01-P5** A linear pair is labeled (3x+10)° and (2x+20)°. Find x and both angles.

3. **4A-01-P6** Explain why vertical angles are equal using a straight angle.
